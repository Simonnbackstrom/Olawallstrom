Varianter extraherade från varumärkesprofilen (Dinmedia för Perspektivo i Sverige AB, 2026).

| Fil | Användning |
|---|---|
| `logo-horizontal.png` | Huvudversion — navbar och ljusa bakgrunder (Papper, Sand). |
| `logo-mark.png` | Bara symbol — favicon, mobil-navbar, profilbilder. |
| `logo-white.png` | Logo på Olablå bakgrund (`#2A62A0`). Behåll bakgrunden i layouten. |
| `logo-negative.png` | Logo på Marin bakgrund (`#173B60`) — orange cirkel + vitt W. Behåll bakgrunden i layouten. |

Vit- och negativ-varianterna har sin varumärkesbakgrund inbakad. Lägg dem på matchande sektionsfärg eller inom ett padding-element med samma färg.

Vektorfiler (SVG/AI) saknas för tillfället — ersätt gärna när Dinmedia levererar.
